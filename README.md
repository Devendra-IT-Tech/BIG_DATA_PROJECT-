# 📊 Retail Analytics & Customer Segmentation Dashboard

An interactive web application built with **Streamlit**, **Plotly**, and **Scikit-Learn** that provides deep retail insights, key performance indicators (KPIs), automated RFM (Recency, Frequency, Monetary) customer clustering, and real-time transaction filtering.

---

## 🚀 Features

- **Real-Time KPIs**: Track Total Revenue, Total Orders, Unique Customers, and Average Order Value (AOV) instantly.
- **RFM Customer Segmentation**: Uses **K-Means Clustering** to automatically categorize customers into actionable segments (*High-Value VIP*, *Loyal Regular*, and *At-Risk / Low Spender*).
- **Interactive Visualizations**: Powered by **Plotly** for responsive, dynamic donut and bar charts.
- **Dynamic Filtering**: Easily filter transactions by category or search through customer IDs and product names.
- **Automated Mock Data Generation**: Automatically generates and saves a robust dataset (`transactions.csv`) if no data source is found.

---

## 🛠️ Tech Stack

- **Frontend & UI**: [Streamlit](https://streamlit.io/)
- **Data Manipulation**: [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Machine Learning**: [Scikit-Learn](https://scikit-learn.org/) (KMeans & StandardScaler)
- **Data Visualization**: [Plotly](https://plotly.com/python/)
